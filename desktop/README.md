# 漫画库 ComicVault · 桌面客户端 v3.0

**这是一个独立软件，不是把网站塞进窗口。** 主窗口加载的是打包在本地的 `app/index.html`，界面、交互、阅读器全部由客户端自己实现；只有数据通过 `/api` 与同一台服务器交换。因此它和网站长得不一样、操作方式也不一样，但账号与漫画完全互通。

| | 网站 / PWA | 桌面客户端 v3.0 |
|---|---|---|
| 界面 | 浏览器 SPA | 本地 `desktop/app/` 独立界面 |
| 导航 | 顶部导航 / 手机底栏 | 左侧固定侧栏 |
| 导入 | 网页文件选择器 | **拖拽文件 / 文件夹**、原生文件对话框 |
| 阅读 | 网页阅读器 | **独立窗口**，键盘翻页 / 双页 / 缩放 / 跳页 |
| 系统能力 | 浏览器限制 | 原生菜单、托盘常驻、快捷键、窗口记忆 |
| 软件下载页 | 网站提供 | **无** |
| 更新 | 刷新即最新 | **设置 → 检查更新** |
| 版本 | 2.3.0 | 3.0.0 |

## 运行

```bash
cd desktop
npm install
npm start
```

也可用项目根目录的 `启动桌面软件.bat` / `启动桌面软件.command`。默认连接线上服务器；用 `CV_DESKTOP_SERVER=http://localhost:8787 npm start` 可指向本机服务。

## 打包

```bash
cd desktop
npm run dist:win     # Windows 安装包 + 便携版 exe
npm run dist:linux   # Linux AppImage
npm run dist:mac     # macOS dmg
```

产物在 `desktop/release/`。`build.files` 只包含 `main.js`、`preload.js`、`app/**/*`、图标与 `package.json`。

## 原生能力

- **拖拽导入**：把图片或整个文件夹拖进窗口，自动递归收集图片、按文件名自然排序、批量上传并分话。
- **文件 → 导入图片 / 文件夹**：调用系统原生文件对话框（`Ctrl+O` / `Ctrl+Shift+O`）。
- **独立阅读窗口**：从漫画详情打开，`←/→` 翻页、空格下一页、`+/-` 缩放、`D` 切单/双页、`Home/End` 跳首尾。
- **系统菜单 / 托盘**：`Ctrl+N` 新建漫画、`F5` 刷新、`Esc` 返回书架；关闭窗口最小化到托盘，托盘菜单可检查更新。
- **设置页**：切换服务器、深浅主题、**检查更新**、在浏览器打开网站。客户端内没有下载页面。

## 数据互通

```
桌面客户端 ─┐
浏览器网页  ├─→ 同一个服务器 / 同一个账号 / 同一份 data ─→ 实时一致
手机客户端 ─┘
```

所有请求由主进程用 `net.fetch` 发出，与窗口共用同一个 session Cookie，因此登录态、封面/页面图片请求都自动带上凭据（托管环境的 `?sharecode=` 由 `endpoint()` 统一补齐）。软件不保存漫画，不复制数据库。

## 验证

```bash
python3 tests/test_desktop_app.py
```

脚本会真实启动 Electron，通过 CDP 断言：加载的是本地界面、桥版本 3.0.0、没有网站导航与下载入口、API 直连可用、设置页检查更新返回 3.0.0。
