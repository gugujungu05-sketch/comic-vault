手动指定服务器地址

手动地址只保存在本机浏览器，不会上传。桌面 / 手机软件里也可在「设置」填同一个服务器地址。
本页由 GitHub Pages 托管，只负责跳转；漫画库本身是带后端与数据库的应用，静态托管跑不起来，所以需要一台常驻服务器。 项目里的 docs/backend.json 由 npm run public-url -- --push 自动更新。
